迭代说明

2026-09-23 通通锁循环钥匙、IC卡、校时与密码短信

更新内容

  • 循环电子钥匙按通通锁 `cyclicConfig` 下发星期几和每日时段；IC 卡有网关且已有卡号时走云端，否则待贴卡后蓝牙回传
  • 指纹和遥控必须在锁旁录入，蓝牙成功后回传 vendorId 激活；删除卡/指纹无网关时同样要蓝牙确认
  • 校时：已连网关走云端，未连网关须蓝牙完成后回传
  • 开门密码支持短信通知并扣减短信余额
  • 首页门锁列表带上可用性：仅蓝牙、网关离线、可远程、远程开关关闭，以及信号强弱

2026-09-21 通通锁删除、键盘密码与低电量

更新内容

  • 删除门锁必须校验登录密码；已在通通锁云端初始化的锁会调用云端删除，并清掉本地钥匙和密码
  • 键盘密码按单次、永久、限期、循环下发。有网关走云端；没网关先保存待激活密码，蓝牙写入后确认。循环只接受每天、工作日、周末或单个星期几
  • 已连网关时，自动闭锁和常开走云端；远程开锁开关仍由 App SDK 写到锁上
  • 低电量阈值默认 20%，可在门锁设置里改；关闭提醒后不再报低电
  • 开锁记录同步最多拉取 5 页

2026-09-21 通通锁导入、云端同步与冻结钥匙

更新内容

  • 可导入科技侠账号下已经添加的锁，不再重复初始化
  • 锁已连网关时，同步接口会拉取电量和近 7 天开锁记录；没连网关则提示到锁旁蓝牙同步
  • 电子钥匙支持冻结和解冻；永久钥匙按通通锁规则下发为长期有效
  • 门锁详情增加可用性：仅蓝牙、网关离线、可远程、远程开关关闭，以及信号强弱

2026-09-19 补齐与通通锁规则不一致的框架行为

更新内容

  • 未连网关的门锁不再按 15 分钟心跳报离线；已连网关超过 30 分钟无信号才报离线
  • 设备转让会清掉原账号的授权用户、钥匙/密码、员工和管理员授权，并解除原网关关联
  • 慧享佳、蓝牙通用锁未配置或本期不支持时改为失败，不再返回模拟成功
  • 新建门锁默认关闭远程开锁

2026-09-17 通通锁接入框架按官方模型调整

更新内容

  • 加锁改为 App SDK 上传 `lockData`，当前用户成为锁管理员
  • 近场开锁改为蓝牙 SDK 完成后上报，服务端不再拿近场请求去打 Cloud API
  • 远程开锁必须已连通通锁网关且打开远程开关，未配置密钥时不再返回模拟成功
  • 新增通通锁用户映射、网关登记、蓝牙钥匙会话接口

package com.yuweishi.iot.lock;

import com.yuweishi.common.enums.LockVendor;
import com.yuweishi.common.exception.BizException;
import org.springframework.stereotype.Component;

import java.util.EnumMap;
import java.util.List;
import java.util.Map;

@Component
public class LockAdapterFactory {
    private final Map<LockVendor, LockCloudAdapter> adapters = new EnumMap<>(LockVendor.class);

    public LockAdapterFactory(List<LockCloudAdapter> list) {
        for (LockCloudAdapter adapter : list) {
            adapters.put(adapter.vendor(), adapter);
        }
    }

    public LockCloudAdapter get(LockVendor vendor) {
        LockCloudAdapter adapter = adapters.get(vendor == null ? LockVendor.TTLOCK : vendor);
        if (adapter == null) {
            throw new BizException("不支持的门锁品牌: " + vendor);
        }
        return adapter;
    }
}
